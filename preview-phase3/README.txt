Devfolio Studio Phase 3 — Standalone Visual Editor

Open standalone.html in Chrome, Edge or Firefox.

The editor demonstrates a responsive drag-and-drop portfolio builder. Choose Layers -> Freeform canvas, then add notes, labels, buttons and images using Properties. Move them with the mouse, resize at the corner, and adjust each device separately. Switch templates, edit profile content, use undo/redo, and export/import JSON.

"Publish demo" only saves a snapshot in this browser. It does NOT publish a website to the internet or create a user account.

If local browser storage is restricted when opening HTML files directly, export your draft as JSON to preserve your work.

For the actual Next.js/Supabase source project see the separate Phase 3 source ZIP.
