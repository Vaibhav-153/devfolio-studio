Devfolio Studio - Phase 2 interactive dashboard demo

QUICK START
Open 'standalone.html' in Chrome, Firefox or Edge. Or open 'index.html'
in this same folder (keep app.js and style.css beside it).

This prototype is browser-only and uses fictional sample data.
Edits are stored in local browser storage, not in Supabase.
There is no real login, public publishing or external GitHub import in this demo.

The complete Next.js source and backend/database integration code are in the
separate source-code ZIP. A live Supabase connection is required to test them.
