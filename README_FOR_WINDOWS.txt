Devfolio Studio Phase 4

QUICK PREVIEW
1. Open the preview-phase4 folder.
2. Double-click index.html. Use Chrome, Edge, or Firefox.
3. Click Publish current draft, edit the draft, switch Published/Draft, restore an old release, or Unpublish.
This HTML demonstration does NOT put a site online.

COMPLETE NEXT.JS APPLICATION
1. Install Node.js 22 and VS Code.
2. Open this source folder in VS Code.
3. Run npm install and then npm run dev (requires Internet and project dependencies).
4. For accounts and real publishing, follow docs/DEPLOYMENT_PHASE4.md to configure Supabase and hosting.
Never expose your SUPABASE_SERVICE_ROLE_KEY to website visitors or commit it to GitHub.
